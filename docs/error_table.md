# エラーコード一覧

## 命名ルール
- 形式: `<CATEGORY>-<3桁番号>`
- 例: AUTH-001, NETWORK-001

---

## カテゴリ一覧
- AUTH: 認証状態の問題
- NETWORK: 通信の問題
- STORAGE: ローカル保存・読込の問題
- SERVER: サーバ内部の問題
- RESPONSE: レスポンス内容の問題
- REQUEST: リクエスト内容の問題

---

## メモ
- エラーは「発生箇所」ではなく「原因」で分類する
- 同じ対応になるエラーはまとめる
- 詳細な原因はログやレスポンスの詳細情報で補足する
- フロントは防御的に実装し、不正レスポンスも考慮する
